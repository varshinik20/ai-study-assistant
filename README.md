
# AI Study Material Assistant

## Project Overview

AI Study Material Assistant is an application designed to help students understand and learn from their study materials more efficiently.

The application will allow users to upload study materials, generate summaries, and ask questions based on the uploaded content.

This project is being developed as an 8-week capstone project.

## Project Objectives

- Simplify the process of studying lengthy materials.
- Generate meaningful summaries from uploaded documents.
- Allow students to ask questions about their study materials.
- Improve learning efficiency through AI-powered assistance.

## Planned Features

- Upload study materials in different document formats.
- Extract and process document content.
- Generate AI-powered summaries.
- Ask questions and receive answers based on uploaded materials.
- Organize and manage study documents.

## Week 1 Progress

### Python Study Notes Analyzer

A command-line Python application that:

- Reads study notes from a text file.
- Counts characters, words, lines, and paragraphs.
- Searches for keywords without case sensitivity.
- Generates an analysis report.
- Handles missing input files.
